## 中文

这里是 gallery 的 Windows 客户端发布仓库，提供安装包、版本说明和校验文件。产品介绍与使用入口见 [gallery 官网](https://galgallery.github.io/)。

### 下载与安装

1. 打开 [最新正式版本](https://github.com/galgallery/gallery-releases/releases/latest)，在 **Assets** 中下载 `gallery-<版本>-windows-x64-setup.exe`。
2. 阅读同版本的 `INSTALLATION.txt`，按需使用 `SHA256SUMS.txt` 核对安装包。
3. 关闭正在运行的 gallery，运行安装器并接受 Windows 管理员确认。首次安装可选择程序目录，升级和修复沿用原目录。

GitHub 自动生成的 `Source code` 压缩包不是客户端安装包。历史安装包和说明见 [全部 Releases](https://github.com/galgallery/gallery-releases/releases)。

### 更新与数据

- 客户端提供中英文界面。后台服务可以在关闭界面后继续处理下载和分享。
- 从 0.2.2 开始，启动后自动检查本仓库的最新正式版本，也可以在“设置 → 程序更新”手动检查。发现新版本时显示全局提示，并提供发布页面和浏览器下载入口。
- 客户端不会自动运行安装器。请下载后自行运行，并确认升级。
- **0.2.1 不支持 GitHub 检查，需先手动安装一次 0.2.2 或更新版本。** 未升级的 0.2.1 不会因为本仓库发布新版本而自动收到 GitHub 更新提示。
- 游戏库、收藏和下载记录保存在 `%ProgramData%\gallery\data`。升级、修复和卸载保留这些数据；选择程序目录不会迁移共享游戏数据。

具体功能、测试范围和已知限制以对应 Release 的说明及安装说明为准。0.2.2 在 Windows 11 家庭版上的完整覆盖安装和系统服务仍需真机验证。

## English

This repository distributes the Windows client for gallery, including installers, release notes and checksum files. Visit the [gallery website](https://galgallery.github.io/?lang=en) for product information and download links.

### Download and install

1. Open the [latest stable release](https://github.com/galgallery/gallery-releases/releases/latest) and download `gallery-<version>-windows-x64-setup.exe` from **Assets**.
2. Read that version's `INSTALLATION.txt`. Use `SHA256SUMS.txt` if you want to verify the installer.
3. Close gallery, run the installer and accept the Windows administrator prompt. Choose an application folder for a new installation; keep the existing folder for upgrades and repairs.

The `Source code` archives generated by GitHub are not client installers. Older installers and their notes are available under [all Releases](https://github.com/galgallery/gallery-releases/releases).

### Updates and your data

- The client offers Chinese and English interfaces. Its background service can continue downloads and sharing after you close the client window.
- Starting with 0.2.2, the client checks this repository's latest stable release after startup. You can also check manually in Settings. A newer version produces an app-wide notice with links to its release page and a browser download.
- The client never runs the installer automatically. Download and run it yourself, then confirm the upgrade.
- **Version 0.2.1 does not check GitHub releases. Install 0.2.2 or a later version manually once.** Publishing a new version here will not send a GitHub update notice to an unmodified 0.2.1 client.
- Your game library, favorites and download records are stored in `%ProgramData%\gallery\data`. Upgrades, repairs and uninstallation retain this data. Choosing an application folder does not move the shared game data.

Refer to each release's notes and installation instructions for its features, validation scope and known limitations. A complete upgrade and system-service validation of 0.2.2 on Windows 11 Home still require testing on a physical computer.
